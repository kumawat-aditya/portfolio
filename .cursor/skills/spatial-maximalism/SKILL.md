# Spatial Maximalism

Treat the viewport as a canvas rather than a container holding a conventional website.

## Core principle

Maximalism does not mean visual overload.

The experience should alternate between:

quiet
→ curious
→ dense
→ absurd
→ quiet
→ expressive
→ quiet

Contrast creates impact.

## Layout

Do not automatically use:

- centered containers
- symmetrical grids
- repeated cards
- uniform spacing
- obvious section boundaries

Prefer:

- asymmetry
- oversized type
- layered compositions
- overlapping planes
- objects escaping the grid
- partial cropping
- negative space
- diagonal relationships
- vertical compositions
- unusual alignment
- controlled overlap

## Spatial hierarchy

Every scene should have:

1. A primary visual focus
2. A secondary discovery
3. Optional tertiary details

Do not make every element visually loud.

## Density

Dense sections should be balanced with visually quiet sections.

Avoid continuous maximalism.

If everything is spectacular, nothing is spectacular.

## Physicality

Elements may feel like physical things rather than UI components.

They can appear:

- placed
- pinned
- leaning
- floating
- hanging
- sliding
- colliding
- escaping
- layered

Use physical metaphors when useful.

## Editorial influence

Composition should occasionally resemble experimental print/editorial layouts.

Large typography may become part of the architecture.

Text may interact with imagery and objects.

## Anti-pattern

Do not convert every section into a collection of floating cards.

Cards are not the default structural language.
